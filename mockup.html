A code holds a string of bits, usually bytes, and gets as many rings as that needs: one ring holds 38 bits (4 bytes), and ring k has 12 + 6k stars at radius 100 + 40k. Ring 0 says how many rings there are and the error-correction level, and all outer rings form one Reed-Solomon codeword. An Astra member number is a payload of exactly 38 bits, so it always fills one ring and cannot be mistaken for bytes. The centre picture is not read: anything, or nothing, may go there, as long as it stays inside radius 73.
Ring radius is fixed at 100; all sizes are relative to it. The scanner expects the defaults (star 19.5, logo 180); other values are for looking only. Every star is a full five-pointed star, the shape of the one in the logo: each limb is solid or the lighter level, the centre is always solid; the scanner works out the lighter level for itself. The code stores metadata × 10¹⁰ + payload in 40 bits; stars 9 to 12 are check symbols. A member ID is the 10-digit payload followed by payload mod 97.
